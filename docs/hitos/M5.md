# M5 — Plugins

Cerrado: 2026-11-20 · Planeado: 22–28 feb 2027 · Etiqueta `v0.1.0`.

## Resumen

`core` ya carga plugins instalados como paquetes aparte: los busca en el grupo de entry points `auditor_dian.plugins` y a cada uno le entrega un `App` con cuatro puntos de extensión (herramientas MCP, informes, lectores de nuevos tipos de documento y la base del cliente en solo lectura). Un plugin no puede reemplazar nada de core, y uno que falla se reporta y se salta sin afectar lo demás. El plugin de ejemplo (`tests/plugin_ejemplo.py`) usa los cuatro puntos: agrega un informe, un lector para un XML inventado y una herramienta MCP. Decisiones en [0008](../decisiones/0008-interfaz-de-plugins.md). Con este hito queda `core` v0.1 interno.

## Hallazgo

Al contar documentos en la prueba del plugin apareció un error de los fixtures, de M2: `factura_cargo_01.xml` tenía el mismo CUFE que la factura de exportación. La exportación nunca entraba a la base común de pruebas, así que la prueba de que "un documento a nombre de otro adquirente no entra en los informes" pasaba sin probar nada. Se corrigió el CUFE; las 98 pruebas pasan con la exportación ya guardada.
