# Resúmenes de hitos

Al cerrar cada hito se escribe `MN.md` (por ejemplo `M1.md`) con un resumen de 5–10 líneas en lenguaje claro y estas métricas:

- Documentos probados (por tipo).
- Número de pruebas y cuántas pasan.
- Cobertura de código.
- Fechas planeadas vs. reales (ver `../cronograma.md`).
- Pendientes que pasan al siguiente hito.
