# M4 — Servidor MCP

Cerrado: 2026-11-20 · Planeado: 8–21 feb 2027.

## Resumen

`auditor mcp` inicia un servidor MCP por stdio que un agente como Claude usa para consultar las facturas de cada cliente. Tiene las seis herramientas de SPEC §10: `listar_clientes`, `buscar_documentos`, `resumen_periodo`, `facturas_credito`, `duplicados_y_anulaciones` y `exportar_informe`. Cada llamada abre la base en solo lectura y la cierra al responder. Los montos salen como texto decimal exacto y cada respuesta lleva el aviso "Cifras calculadas a partir de los documentos cargados. Requiere revisión del contador.". `resumen_periodo` entrega las cifras ya sumadas con sus CUFE, para que el agente no calcule nada. La única herramienta que escribe es `exportar_informe`, que solo crea archivos `.xlsx` nuevos. Decisiones en [0007](../decisiones/0007-servidor-mcp.md).

## Criterio de cierre

Un agente de Claude Code 2.1, en modo no interactivo y conectado al servidor por stdio, respondió "¿Cuánto IVA facturado en compras hubo en el bimestre 1 de 2026?" con **40.500 COP y la lista exacta de sus 3 CUFE**, más el aviso del SPEC. Es la misma cifra que la prueba `test_iva_del_bimestre_1_con_sus_cufes`, cuyo valor se calculó a mano a partir de los fixtures. Además, el servidor respondió sobre las tres bases con facturas reales.
